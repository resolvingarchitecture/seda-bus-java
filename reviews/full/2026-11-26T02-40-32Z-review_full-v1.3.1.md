## Needs Attention Now

The 7 most serious of 34 high-severity problems; the others are first under Other Improvements. Tick each off as it is fixed.

- [ ] 🔴 **Implementation differs from the design: Routing slip advanced on completion.** SEDAMessageChannel.process acks (deletes persisted file) before SEDABus.completed forwards; a failed forward is ignored. **Fix:** Ack only after the next stage accepts.
- [ ] 🔴 **Implementation differs from the design: Three service levels with persist-before-enqueue and ordered replay.** persist and sorted replay are implemented, but ExactlyOnce dedup is in memory only and DropOldest leaves evicted files to replay. **Fix:** Persist dedup; remove evicted envelopes' files.
- [ ] 🔴 **Implementation differs from the design: Backpressure policies Reject/DropNewest/DropOldest/Block.** Backpressure.java documents a Block timeout, but admit uses queue.put with no timeout; DropOldest evictions are not reported. **Fix:** Add a timeout; report evictions.
- [ ] 🔴 **Implementation differs from the design: Throwing consumer isolated; exhausted retries dead-lettered.** deadLetter returns false when channelDir is null (AtMostOnce), then ack discards the envelope. **Fix:** Provide a dead-letter sink for all levels.
- [ ] 🔴 **Implementation differs from the design: Bounded memory, no thread leak.** repeatedLifecyclesDoNotLeakThreads passes, but SEDABus.callbacks keeps entries for dead-lettered envelopes. **Fix:** Remove the callback on dead-letter.
- [ ] 🔴 **A high-priority stakeholder need is not delivered: The Java port stays faithful to the shared design and the correctness suite as the other ports change.** Staged design is implemented and tested, but conformance relies on hand-mapped tests. **Fix:** Run shared vectors in CI.
- [ ] 🔴 **A high-priority stakeholder need is not delivered: No envelope is lost or delivered twice under concurrent load, retries and shutdown.** Loss is possible via DropOldest, failed AtMostOnce dead-lettering and ack before forward; duplicates after crash. **Fix:** Close these loss paths and persist dedup.

## Other Observations

### Application

#### seda-bus Java library

**Observability** — _medium_

For a library the expected bar is cheap counters plus a failure hook. Today only log lines and queued() exist, so hosts cannot count rejections, retries, dead-letters or lost callbacks. The TODO ChannelMetrics listener is the right-sized fix.

Gaps:

- No programmatic dead-letter or rejection event hook
- No envelope-id correlation across hops

**Testability** — _high_

Coverage is good and well commented, but several tests prove less than their C-mapping claims, which weakens the 7-of-7 conformance claim.

Gaps:

- C7 uses a CountDownLatch that cannot detect duplicates, so 'exactly once' is unverified
- C2 dead-letter tests assert only tries and queued()==0, never that a dead-letter record exists (which would expose the AtMostOnce no-op)
- No crash/replay tests, and the C4 assertion is conditional on drained==true; deliversPointToPoint is flaky
