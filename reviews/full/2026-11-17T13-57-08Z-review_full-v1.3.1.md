## Domain Reviews

### Application

#### seda-bus (Java) library

**Observability** — _medium_

Proportionate expectations for a library are cheap counters (queue depth, rejected sends, retries, dead-letters, replayed count) and a failure/dead-letter event hook. The Backpressure component is an admission signal and may already expose saturation, but this cannot be confirmed without code. Metrics hooks are explicitly deferred to the roadmap. A logging framework, dashboards, tracing and alerting do not apply to an in-process library and are not reported as gaps.

Gaps:

- No evidence of a dead-letter or failure callback. Dead-lettered envelopes go only to a file, so hosts (service-bus) cannot react programmatically to poison messages (unverified).
- No evidence of per-channel counters for rejections and retries. Hot-looping retries (no backoff) would be invisible to the host.
- Recommend a minimal, dependency-free listener interface plus read-only counters, defined once and mirrored across ports.

**Testability** — _high_

This is the weakest area relative to what the library promises. One test class covers both the engine and replay, and the capacity/retry/dead-letter tests are timing-sensitive and flaky. The accepted decision to use latches and an injected clock is the right remedy, but it requires a clock abstraction that is not yet part of the described design.

Gaps:

- No crash-recovery tests backing the mandatory zero-loss NFR. Examples: interrupting between persist and enqueue, between handler completion and record removal, and mid-write of a partial file.
- No tests described for replay ordering under concurrent publishers or for ExactlyOnce dedup across a restart.
- No cross-port conformance suite. Behavioural lockstep across seven languages is asserted but not verified; a shared language-neutral scenario suite (inputs/expected outcomes) would make the parity goal testable.
- No injectable clock/executor seam described; needed for deterministic retry and backoff tests once backoff ships.
- No JDK 11 test run evidenced.
