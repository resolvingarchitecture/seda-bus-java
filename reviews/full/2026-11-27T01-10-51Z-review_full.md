## Design quality · 40%

**Progress: 4 of 46 tasks done (9%)** ▰▱▱▱▱▱▱▱▱▱

- [ ] 🔴 **The public surface is explicit and the rest is internal.** There is no module-info or API list. getSubscriptionChannels returns the internal mutable list. **Fix:** List the public API and return unmodifiable views.
- [ ] 🔴 **The public contract is documented.** Javadoc covers semantics but not thread-safety, nullability or error contract per public method. **Fix:** Document inputs, errors and thread-safety on each public method.
- [ ] 🔴 **A versioning and compatibility policy exists.** No versioning or deprecation policy appears in README, DESIGN or CHANGELOG. **Fix:** State a semver policy and a deprecation window.
- [ ] 🔴 **Lifecycle is defined, including what happens to work in flight.** restart() builds a new pool without per-channel permits and never unpauses channels. A second start() leaks the old pool. Queued AtMostOnce work is dropped silently at timeout. **Fix:** Make start idempotent, re-register permits, and report abandoned queued envelopes.
- [ ] 🔴 **Thread-safety is stated for every shared component.** DESIGN concurrency notes are partial. Per-class thread-safety is not stated. **Fix:** State the thread-safety of SEDABus, the channel and the pool.
- [ ] 🔴 **Every queue, buffer, cache and map is bounded, with a stated policy at the limit.** deadLetter.json grows without bound; TODO admits this. The callbacks map is bounded only by producers. **Fix:** Rotate or cap the dead-letter file and document the limits.
- [ ] 🔴 **Failure modes are listed for each operation.** Failure modes are described in prose, not per public operation (publish, completed, sendUnprocessed). **Fix:** Add a per-operation failure table.
- [ ] 🔴 **No failure is silent.** giveUp ignores a false return from deadLetter (IOException), then ack deletes the persisted copy. The envelope is lost. **Fix:** Keep the persisted copy when the dead-letter write fails.
- [ ] 🔴 **Retry is bounded, backed off, and safe.** Retry is bounded with backoff and jitter. A partial fanOut failure retries the whole envelope and duplicates it to subscribers that already received it. **Fix:** Track per-subscriber hand-over and retry only the failed copies.
- [ ] 🔴 **Delivery guarantees match the implementation.** Persist-before-enqueue and ack-after-hand-over hold. Replay is not automatic at start, and sendUnprocessed processes inline, bypassing queue and permits. **Fix:** Replay through the queue and document that the host must call resumeUnprocessed.
- [ ] 🔴 **Failure paths and concurrency are tested, and time and I/O can be faked.** Consumer exception, rejected forward and concurrency are tested. There are no crash-mid-write tests and no injectable clock; tests rely on sleeps. **Fix:** Add fault-injection tests and an injectable clock or file system.
- [ ] 🔴 **Documentation matches the code.** DESIGN routing pseudocode ratchets before lookup. TODO says retries are immediate. The Block Javadoc cites a nonexistent timeout. DESIGN says persisted envelopes replay at start. **Fix:** Update DESIGN, TODO and Javadoc to match the code.
- [ ] 🔴 **The project can continue if its owner is unavailable.** Build steps are documented. Release credentials and the jitpack process are not written down. **Fix:** Document the release steps and access.
- [ ] 🔴 **Contracts are machine-readable and tested.** CORRECTNESS_SUITE.md is prose. Ports map tests to it by hand; there are no shared vectors. **Fix:** Publish shared test vectors each port runs.
- [ ] 🔴 **Change follows compatibility rules.** No compatibility or deprecation rules exist for the MessageBus surface. **Fix:** Adopt additive-only changes and a deprecation window.
- [ ] 🔴 **Delivery semantics and ordering are stated for each channel.** Delivery levels are stated; ordering per channel is not. **Fix:** State ordering per channel.
- [ ] 🔴 **Complexity does not exceed team capacity.** One maintainer keeps seven ports in lockstep without automated conformance. **Fix:** Automate cross-port conformance or reduce the scope.
- [ ] 🟡 **Persistence sits behind a boundary.** persist, removePersisted, delivered.log and deadLetter I/O are inline in SEDAMessageChannel. There is no store class. **Fix:** Extract a ChannelStore boundary for envelope, dead-letter and dedup files.
- [ ] 🟡 **Components are cohesive and of reasonable size.** SEDAMessageChannel is about 700 lines. It handles queueing, delivery, fan-out, retry, dead-letter, persistence and the dedup log. **Fix:** Split out persistence and retry or dead-letter collaborators.
- [ ] 🟡 **Failures are reported in one consistent way.** Failures surface in several ways: a boolean from publish, error text on the callback envelope, a DeadLetterListener, or logs only (unknown channel). **Fix:** Document one failure channel per operation.
- [ ] 🟡 **Ordering guarantees are stated, and so is where they stop.** Ordering is not stated. Retries re-enqueue at the tail, and concurrency above 1 reorders. **Fix:** Document FIFO only at concurrency 1 with no retries.
- [ ] 🟡 **Overload is handled deliberately.** Block uses queue.put with no timeout. completed() hand-over to a Block stage can park worker threads indefinitely. **Fix:** Add a send timeout; never block workers on hand-over.
- [ ] 🟡 **Resources are released on every path.** start() called twice creates a new pool and timer without stopping the old ones. **Fix:** Guard start against Running state.
- [ ] 🟡 **Durable writes follow a stated protocol.** persist writes a tmp file then does an atomic move, with no fsync of file or directory. Leftover .tmp files are never removed. **Fix:** Fsync file and directory; clean .tmp files at start.
- [ ] 🟡 **On-disk and wire formats are documented and versioned.** The envelope JSON and file naming are undocumented and unversioned; TODO lists this. **Fix:** Document the format with a version marker.
- [ ] 🟡 **Compatibility is checked automatically for a library with dependents.** pom.xml has no japicmp or equivalent, yet there are downstream dependents. **Fix:** Add a japicmp check against the last release.
- [ ] 🟡 **The trust boundary is stated and input is validated at it.** The trust boundary (in-process caller, files on disk) is not stated. **Fix:** State that the caller is trusted and the store directory is untrusted on replay.
- [ ] 🟡 **Replayed or parsed data is handled safely.** In sendUnprocessed, e.fromJSON on a corrupt file is uncaught, so one bad file aborts the replay. **Fix:** Catch parse errors and quarantine bad files.
- [ ] 🟡 **The build is reproducible and the target is tested.** CI clones ra-common HEAD rather than pinned 1.2.0. CI tests only Java 17 while the target is 11. **Fix:** Pin the ra-common tag and add Java 11 to CI.
- [ ] 🟡 **Swallowed errors.** deadLetter IOException is only logged before the copy is deleted. A failed appendDelivered is only logged. **Fix:** Propagate failures that affect guarantees.
- [ ] 🟡 **Build, buy or reuse is a decision for each major capability.** There is no record of why the bus is built rather than reusing an existing in-process queue library. **Fix:** Record the build-versus-reuse rationale.
- [ ] 🟡 **Shared components have a lifecycle and versioning.** No release process or deprecation path is stated. TODO notes the library is not published to a real repository. **Fix:** Define the release and deprecation process.
- [ ] 🟡 **Key-person risk is identified with a mitigation.** A single maintainer holds all ports and the release path. The risk is not recorded. **Fix:** Record key-person risk and its mitigation.

- [ ] 🟡 **Builds and releases are automated.** ci.yml only runs tests. Release is manual through jitpack. **Fix:** Automate tagging and publishing.
- [ ] 🟡 **Supported runtime versions are stated and tested.** The Java 11 target is stated, but CI runs only Java 17. **Fix:** Add a Java 11 and 17 CI matrix.
