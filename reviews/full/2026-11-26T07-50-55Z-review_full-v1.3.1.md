## Design quality · 44%

**Progress: 0 of 51 tasks done (0%)** ▱▱▱▱▱▱▱▱▱▱

- [ ] 🔴 **The public contract is documented.** The Javadoc does not state nullability, thread-safety or errors for each public method of SEDABus or SEDAMessageChannel. **Fix:** Document inputs, errors, nullability and thread-safety for each public method.
- [ ] 🔴 **A versioning and compatibility policy exists.** A CHANGELOG exists, but no semver or breaking-change policy is stated. Unreleased makes SEDAMessageChannel public. **Fix:** State the semver rules and the deprecation window.
- [ ] 🔴 **Lifecycle is defined, including what happens to work in flight.** start() is not idempotent: it creates a new pool and timer. restart() does not restart channels or re-register concurrency permits. **Fix:** Make start idempotent and restart the channels on restart.
- [ ] 🔴 **Thread-safety is stated for every shared component.** DESIGN.md has general concurrency notes, but no per-class thread-safety statement. **Fix:** State thread-safety on each public class.
- [ ] 🔴 **Every queue, buffer, cache and map is bounded, with a stated policy at the limit.** deadLetter.json grows without bound (TODO.md). Block uses queue.put with no timeout, although the enum doc claims a send timeout. **Fix:** Rotate or bound the dead-letter file and add a Block timeout.
- [ ] 🔴 **Failure modes are listed for each operation.** DESIGN.md covers retry and shutdown, but there is no per-operation failure list for publish or registerChannel. **Fix:** Add a failure table for each public operation.
- [ ] 🔴 **No failure is silent.** giveUp ignores the false return of deadLetter() and then acks, deleting the persisted copy. The envelope can be lost. **Fix:** Keep the persisted copy when the dead-letter write fails.
- [ ] 🔴 **Delivery guarantees match the implementation.** fanOut returns false if any subscriber publish fails. The retry re-fans to every subscriber, duplicating deliveries to those that succeeded. **Fix:** Track per-subscriber success and retry only the failed ones.
- [ ] 🔴 **Deduplication state is as durable as the guarantee it supports.** appendDelivered only logs an IO failure. Compaction is synchronized but appends are not, so a concurrent append can be lost. **Fix:** Synchronize append with compaction and surface write failures.
- [ ] 🔴 **Failure paths and concurrency are tested, and time and I/O can be faked.** Consumer-exception and refused-forward tests exist. There are no crash-mid-write tests and no injectable clock, and tests rely on sleeps. **Fix:** Add fault-injection tests and an injectable clock.
- [ ] 🔴 **Documentation matches the code.** TODO.md says retry backoff is missing (it is implemented). The DESIGN routing pseudocode and capacity note predate the hand-over and backpressure changes. **Fix:** Update TODO.md and DESIGN.md.
- [ ] 🔴 **Recovery after a partial write is defined.** .json.tmp leftovers are ignored but never removed. A corrupt .json file breaks replay. **Fix:** Remove temp files at start and quarantine corrupt files.
- [ ] 🔴 **Change follows compatibility rules.** No deprecation window or additive-change rule is stated. **Fix:** Adopt and document compatibility rules.
- [ ] 🔴 **Delivery semantics and ordering are stated for each channel.** Delivery levels are stated but ordering is not. **Fix:** State ordering per channel.
- [ ] 🔴 **Exactly-once claims hold end to end.** The crash window is documented. Pub/sub retry re-delivers to subscribers that already succeeded, which is undocumented. **Fix:** Fix the fan-out retry or document it.
- [ ] 🔴 **Complexity does not exceed team capacity.** One person maintains seven language ports plus a shared suite. **Fix:** Prioritise ports or add maintainers.
- [ ] 🔴 **Releases are signed and their integrity can be checked.** Releases are distributed via jitpack only. No signing is configured in pom.xml. **Fix:** Sign artefacts and publish checksums.
- [ ] 🟡 **Persistence sits behind a boundary.** persist, removePersisted, deadLetter and delivered.log file I/O are written inline in SEDAMessageChannel. **Fix:** Extract a ChannelStore class that owns all file access.
- [ ] 🟡 **Components are cohesive and of reasonable size.** SEDAMessageChannel (~600 lines) combines queueing, delivery, retry, dead-letter, persistence and the dedup log. **Fix:** Split out persistence and retry or dead-letter handling.
- [ ] 🟡 **Failures are reported in one consistent way.** Failures surface in several ways: a false return, DLC error messages, the callback, DeadLetterListener, or a log line only. **Fix:** Document which channel reports which failure.
- [ ] 🟡 **Ordering guarantees are stated, and so is where they stop.** No ordering guarantee is stated. Retries re-queue at the tail, and concurrency above one reorders envelopes. **Fix:** Document per-channel FIFO and the cases that break it.
- [ ] 🟡 **Durable writes follow a stated protocol.** persist uses a temp file and ATOMIC_MOVE but does not fsync the file or the directory. The protocol is undocumented. **Fix:** fsync before the move and document the protocol.
- [ ] 🟡 **On-disk and wire formats are documented and versioned.** The persisted JSON and filename format are undocumented and unversioned. TODO.md admits this. **Fix:** Document the format and add a version marker.
- [ ] 🟡 **Compatibility is checked automatically for a library with dependents.** No japicmp or similar step in pom.xml or ci.yml. **Fix:** Add an API compatibility check to the build.
- [ ] 🟡 **The trust boundary is stated and input is validated at it.** The trust in the in-process caller and in files on disk is not stated. **Fix:** State the trust boundary in DESIGN.md.
- [ ] 🟡 **Replayed or parsed data is handled safely.** sendUnprocessed calls fromJSON with no try/catch. A corrupt file can abort the replay loop. **Fix:** Catch parse errors and quarantine bad files.
- [ ] 🟡 **The build is reproducible and the target is tested.** CI clones ra-common HEAD rather than the pinned 1.2.0, and tests only on JDK 17 while the target is 11. **Fix:** Build the pinned ra-common tag and test on JDK 11.
- [ ] 🟡 **Swallowed errors.** Failures of removePersisted and appendDelivered are only logged. The deadLetter() result is ignored. **Fix:** Propagate or report these via the listener.
- [ ] 🟡 **Schema changes are managed.** No format version or migration exists. **Fix:** Version the store format.
- [ ] 🟡 **Retention is defined for each data set.** No retention is defined for deadLetter.json or leftover .tmp files. **Fix:** Define retention and cleanup.
- [ ] 🟡 **The logical data model is documented.** The store files (envelopes, deadLetter.json, delivered.log) are not documented. **Fix:** Document the files and their fields.

- [ ] 🟡 **The files a library writes are located, owned and bounded.** locationBase is configurable. Permissions, volume and cleanup are not stated. **Fix:** Document permissions, size bounds and cleanup.
- [ ] 🟡 **The format is versioned and migratable.** Nothing says whether old files remain readable. **Fix:** State a format compatibility policy.
- [ ] 🟡 **Build, buy or reuse is a decision for each major capability.** No record explains building this rather than reusing an existing in-process bus. **Fix:** Record the build rationale.
- [ ] 🟡 **Shared components have a lifecycle and versioning.** There is no deprecation path, and the library is published only via jitpack (TODO.md). **Fix:** Define the release and deprecation process.
