## Design quality · 44%

**Progress: 4 of 45 tasks done (9%)** ▰▱▱▱▱▱▱▱▱▱

- [ ] 🔴 **The public surface is explicit and the rest is internal.** No public API list. SEDAMessageChannel is public with mutable setters; WorkerThreadPool is package-private. **Fix:** List the supported public API in README and mark the rest internal.
- [ ] 🔴 **The public contract is documented.** Javadoc covers semantics only partly. Nullability, errors and thread-safety per public method are not stated. **Fix:** Document inputs, return meaning, errors and thread-safety per public method.
- [ ] 🔴 **A versioning and compatibility policy exists.** CHANGELOG has versions, but no policy defines breaking changes or deprecation. **Fix:** Add a semver and deprecation policy.
- [ ] 🔴 **Lifecycle is defined, including what happens to work in flight.** start() is not idempotent: a second call creates a new pool and timer without stopping the old ones. Channel drain ignores in-flight work. **Fix:** Guard start/shutdown against repeat calls; count in-flight envelopes in drainWithin.
- [ ] 🔴 **Thread-safety is stated for every shared component.** DESIGN concurrency notes are partial. Per-class thread-safety (SEDABus, channel setters) is not stated. **Fix:** State the thread-safety contract on each public class.
- [ ] 🔴 **Every queue, buffer, cache and map is bounded, with a stated policy at the limit.** deadLetter.json grows unbounded (TODO admits it). Block uses queue.put with no timeout, despite the enum doc. **Fix:** Rotate or cap dead-letter files; add a Block timeout.
- [ ] 🔴 **Failure modes are listed for each operation.** No per-operation failure list. publish false covers paused, filter, capacity and persist failures. **Fix:** Add a failure table per public operation.
- [ ] 🔴 **No failure is silent.** giveUp ignores deadLetter() false, then ack() deletes the persisted copy. A dead-letter write failure loses the envelope. **Fix:** Keep the persisted copy and notify the listener when the dead-letter write fails.
- [ ] 🔴 **Delivery guarantees match the implementation.** An AtLeastOnce/ExactlyOnce envelope on an AtMostOnce channel is not persisted: channelDir is null, so persist() returns true. **Fix:** Reject or persist guaranteed envelopes on non-persistent channels, and document it.
- [ ] 🔴 **Failure paths and concurrency are tested, and time and I/O can be faked.** Consumer-exception and rejected-forward tests exist. No crash-mid-write tests, no injectable clock or FS; tests use sleeps. **Fix:** Add fault-injection and clock seams, as TODO lists.
- [ ] 🔴 **Documentation matches the code.** DESIGN routing pseudocode, 'full queue fails send', TODO 'immediate re-queue' and the Block 'send timeout' doc contradict the code. **Fix:** Update DESIGN, TODO and Backpressure Javadoc to match the code.
- [ ] 🔴 **The project can continue if its owner is unavailable.** Build steps exist in README and CI, but no release or access handover is documented. **Fix:** Document release steps and access recovery.
- [ ] 🔴 **Change follows compatibility rules.** No additive-only or deprecation rules. **Fix:** Adopt compatibility rules with a deprecation window.
- [ ] 🔴 **Delivery semantics and ordering are stated for each channel.** Delivery levels are stated per channel; ordering is not. **Fix:** Add ordering guarantees per channel mode.
- [ ] 🔴 **Complexity does not exceed team capacity.** One maintainer across seven ports. Recent fixes show recurring defects in delivery paths. **Fix:** Assess capacity; prioritise the conformance suite over port count.
- [ ] 🟡 **Persistence sits behind a boundary.** persist, removePersisted, delivered.log and deadLetter.json file I/O sit inline in SEDAMessageChannel, with no store class. **Fix:** Extract a ChannelStore boundary for envelope, dedup and dead-letter files.
- [ ] 🟡 **Components are cohesive and of reasonable size.** SEDAMessageChannel (~700 lines) does queueing, delivery, retry, dead-letter, persistence, dedup log and compaction. **Fix:** Split out persistence/dedup and retry scheduling.
- [ ] 🟡 **Failures are reported in one consistent way.** Failures surface as a boolean false (one false for many causes), DLC error messages, callbacks or the listener. **Fix:** Document one failure channel and distinguish rejection reasons.
- [ ] 🟡 **Ordering guarantees are stated, and so is where they stop.** Ordering is not documented. Concurrency above one, retries and fan-out reorder envelopes. **Fix:** State per-channel FIFO only at concurrency 1 without retries.
- [ ] 🟡 **Overload is handled deliberately.** A Block policy on the next stage blocks worker threads inside completed() and fanOut with no timeout. This can stall the pool. **Fix:** Use a timed offer on hand-over, never an unbounded put.
- [ ] 🟡 **Durable writes follow a stated protocol.** persist uses temp file plus ATOMIC_MOVE but no fsync of file or directory. Leftover .tmp files are ignored, never removed. **Fix:** Fsync before rename; clean up .tmp files at start.
- [ ] 🟡 **On-disk and wire formats are documented and versioned.** Envelope JSON and filename format are undocumented and unversioned (TODO item). **Fix:** Document and version the on-disk format.
- [ ] 🟡 **Compatibility is checked automatically for a library with dependents.** pom.xml has no japicmp or API-compatibility check, despite downstream service-bus and 1M5. **Fix:** Add japicmp against the previous release.
- [ ] 🟡 **The trust boundary is stated and input is validated at it.** No statement of trust in the in-process caller or the store directory. **Fix:** State the trust boundary: in-process caller and host-owned files.
- [ ] 🟡 **Replayed or parsed data is handled safely.** sendUnprocessed calls e.fromJSON on file content without catching parse errors. One corrupt file aborts the replay. **Fix:** Catch parse failures and quarantine corrupt files.
- [ ] 🟡 **Sensitive data is not kept or logged in clear unless that is a decision.** Full envelopes are persisted in clear JSON, including dead letters, with no classification or decision. **Fix:** Record that the host owns payload sensitivity and file permissions.
- [ ] 🟡 **The build is reproducible and the target is tested.** CI builds ra-common from HEAD, not the pinned 1.2.0, and tests on JDK 17 only while targeting 11. **Fix:** Pin ra-common in CI; add JDK 11 to the matrix.
- [ ] 🟡 **Swallowed errors.** A removePersisted delete failure is only logged, so the envelope is replayed later as if undelivered. **Fix:** Surface delete failures through the listener or a counter.
- [ ] 🟡 **Build, buy or reuse is a decision for each major capability.** No record of why the bus is built rather than reusing an existing in-process bus or queue library. **Fix:** Record the build-vs-reuse rationale.
- [ ] 🟡 **Shared components have a lifecycle and versioning.** No deprecation path. Publishing is local/jitpack only (TODO). **Fix:** Define a release and deprecation process.
