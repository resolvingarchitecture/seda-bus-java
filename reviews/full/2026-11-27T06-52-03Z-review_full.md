## Design quality · 42%

**Progress: 6 of 48 tasks done (13%)** ▰▱▱▱▱▱▱▱▱▱

- [ ] 🔴 **The public surface is explicit and the rest is internal.** SEDAMessageChannel is now public with mutable setters; no module-info and no list of the supported API. **Fix:** List the supported public API; add module-info or mark internals as internal.
- [ ] 🔴 **The public contract is documented.** Javadoc is partial; per-operation errors, nullability and thread-safety are not stated. **Fix:** Document each public method's inputs, return values, errors and thread-safety.
- [ ] 🔴 **A versioning and compatibility policy exists.** No versioning or deprecation policy; SEDAMessageChannel was made public under an Unreleased entry. **Fix:** State a semver policy and a deprecation window.
- [ ] 🔴 **Lifecycle is defined, including what happens to work in flight.** start() creates a new pool and timer without stopping old ones; channel drainWithin counts only queued(), not in-flight work. **Fix:** Make start/shutdown idempotent; count in-flight work when draining.
- [ ] 🔴 **Thread-safety is stated for every shared component.** DESIGN concurrency notes are general; no per-class thread-safety statement. **Fix:** State the thread-safety of each public class.
- [ ] 🔴 **Every queue, buffer, cache and map is bounded, with a stated policy at the limit.** deadLetter.json grows without limit (TODO.md); Block uses queue.put with no timeout. **Fix:** Rotate or cap dead-letter files; add a Block timeout.
- [ ] 🔴 **Failure modes are listed for each operation.** DESIGN covers retry and give-up, not failures per public operation. **Fix:** Add a per-operation failure table.
- [ ] 🔴 **No failure is silent.** giveUp ignores deadLetter()'s false result on IOException, then acks and deletes the persisted copy. **Fix:** Keep the persisted copy if writing the dead letter fails.
- [ ] 🔴 **Retry is bounded, backed off, and safe.** Retry is bounded with backoff, but a partial pubSub fanOut failure re-publishes to all subscribers, duplicating copies. **Fix:** Retry only the subscribers that failed.
- [ ] 🔴 **Delivery guarantees match the implementation.** An envelope-level AtLeastOnce/ExactlyOnce on an AtMostOnce channel is not persisted (channelDir null), yet send returns true. **Fix:** Reject or persist envelopes whose level exceeds the channel's level.
- [ ] 🔴 **Failure paths and concurrency are tested, and time and I/O can be faked.** Tests cover consumer exceptions and concurrency, but no crash-mid-write tests and no injectable clock; tests rely on sleeps. **Fix:** Add fault-injection tests and an injectable clock/filesystem.
- [ ] 🔴 **Documentation matches the code.** TODO says retries are immediate; Backpressure.Block mentions a send timeout that doesn't exist; DropNewest 'silently discard' actually returns false. **Fix:** Bring TODO.md and the Backpressure Javadoc in line with the code.
- [ ] 🔴 **The project can continue if its owner is unavailable.** The release process and jitpack/repository access are not documented. **Fix:** Write a release runbook.
- [ ] 🔴 **Contracts are machine-readable and tested.** CORRECTNESS_SUITE.md is prose; no machine-readable shared vectors (TODO lists a conformance suite). **Fix:** Publish shared test vectors that every port runs.
- [ ] 🔴 **Change follows compatibility rules.** No stated compatibility or deprecation rules for the bus API. **Fix:** Adopt additive-only changes with a deprecation window.
- [ ] 🔴 **Delivery semantics and ordering are stated for each channel.** Delivery semantics are stated per level; ordering is not stated per channel. **Fix:** Add ordering per channel (see RULE-APP-034).
- [ ] 🔴 **Complexity does not exceed team capacity.** One maintainer keeps seven language ports in step with prose-only conformance. **Fix:** Automate conformance to reduce the load.
- [ ] 🟡 **Persistence sits behind a boundary.** persist, removePersisted, deadLetter and delivered.log file I/O all sit inside SEDAMessageChannel. **Fix:** Extract a channel store class that owns envelope, dead-letter and delivered-log files.
- [ ] 🟡 **Components are cohesive and of reasonable size.** SEDAMessageChannel (~600 lines) handles queueing, delivery, retry, dead-letter, persistence, dedup and lifecycle. **Fix:** Split out persistence/dedup and retry scheduling.
- [ ] 🟡 **Failures are reported in one consistent way.** Failure reaches callers as a boolean, an envelope error message, a callback, a listener or a log, depending on the path. **Fix:** Document a single failure-reporting model and map every path to it.
- [ ] 🟡 **Ordering guarantees are stated, and so is where they stop.** Ordering is not documented; retries re-queue at the tail and concurrency above one reorders. **Fix:** Document per-channel FIFO and what breaks it.
- [ ] 🟡 **Durable writes follow a stated protocol.** persist uses temp file plus ATOMIC_MOVE, but neither file nor directory is fsynced; the protocol is undocumented. **Fix:** Fsync file and directory; document the write protocol.
- [ ] 🟡 **On-disk and wire formats are documented and versioned.** Persisted JSON and filename format are unversioned and undocumented (TODO.md item). **Fix:** Document the format and add a version field.
- [ ] 🟡 **Compatibility is checked automatically for a library with dependents.** pom.xml has no API compatibility check, although service-bus and 1M5 depend on the library. **Fix:** Add japicmp to the build.
- [ ] 🟡 **The trust boundary is stated and input is validated at it.** The trust in the in-process caller and in the on-disk store is not stated. **Fix:** State the trust boundary in DESIGN.md.
- [ ] 🟡 **Replayed or parsed data is handled safely.** sendUnprocessed calls fromJSON without catching runtime errors; leftover .tmp files are never removed. **Fix:** Quarantine corrupt files and remove leftover temp files at start.
- [ ] 🟡 **Sensitive data is not kept or logged in clear unless that is a decision.** Full envelope JSON is persisted in clear in the user app-data directory; this is not classified or recorded as a decision. **Fix:** State that payloads are stored in clear and that the host owns them.
- [ ] 🟡 **The build is reproducible and the target is tested.** Release target is 11 but CI runs only JDK 17; CI builds ra-common from HEAD, not the pinned 1.2.0. **Fix:** Run CI on JDK 11 and check out the ra-common 1.2.0 tag.
- [ ] 🟡 **Swallowed errors.** deadLetter IOException and removePersisted delete failures are only logged; the drain catch logs RuntimeException. **Fix:** Propagate these failures to the listener or keep the persisted copy.
- [ ] 🟡 **Build, buy or reuse is a decision for each major capability.** No record of why the bus is built rather than reusing an existing library. **Fix:** Record the build-versus-reuse rationale.
- [ ] 🟡 **Shared components have a lifecycle and versioning.** Not published to a real repository (TODO); no deprecation path. **Fix:** Publish to Maven Central with a deprecation policy.
- [ ] 🟡 **Key-person risk is identified with a mitigation.** Brian is the sole maintainer of seven ports; no key-person risk is recorded. **Fix:** Record the risk and a mitigation.
- [ ] 🟡 **A risk register has an owner and a status for each risk.** risk-ee1187f5 "The adaptive SEDA controller is not implemented, so a sta..." lacks status; risk-93dd2efa "AtLeastOnce replays envelopes after a crash, so consumers..." lacks status; risk-bd402213 "The deliversPointToPoint test is flaky under repeated bac..." lacks status.
- [ ] 🟡 **Builds and releases are automated.** ci.yml only tests; releases are via jitpack with no release job. **Fix:** Add a tagged release workflow.
- [ ] 🟡 **Supported runtime versions are stated and tested.** Java 11 is targeted; CI runs only temurin 17. **Fix:** Add a CI matrix covering 11 and 17.
- [ ] 🟡 **The resource footprint is documented and configurable.** ra.sedabus.pool.max and channel.locationBase exist in code but are not documented in README/DESIGN. **Fix:** Document the thread, memory and disk defaults and their properties.
