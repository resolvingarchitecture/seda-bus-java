## Design quality · 47%

**Progress: 6 of 44 tasks done (14%)** ▰▱▱▱▱▱▱▱▱▱

- [ ] 🔴 **The public contract is documented.** Javadoc covers semantics but not nullability, thread-safety or errors for each public method (publish, registerChannel, getChannel). **Fix:** Document inputs, returns, errors and thread-safety for each public method.
- [ ] 🔴 **A versioning and compatibility policy exists.** No versioning or deprecation policy in README, DESIGN or CHANGELOG. **Fix:** State a semver policy and what counts as breaking.
- [ ] 🔴 **Lifecycle is defined, including what happens to work in flight.** SEDABus.start is not idempotent: a second call replaces the pool and retryTimer without stopping them. Channel drainWithin ignores in-flight envelopes. **Fix:** Guard start against a running bus and document in-flight handling.
- [ ] 🔴 **Thread-safety is stated for every shared component.** DESIGN concurrency notes are general; no per-class thread-safety statement for SEDABus or SEDAMessageChannel public methods. **Fix:** State the thread-safety of each public class.
- [ ] 🔴 **Every queue, buffer, cache and map is bounded, with a stated policy at the limit.** Block uses queue.put with no timeout despite Backpressure doc saying 'up to the send timeout'. deadLetter.json grows unbounded (TODO). **Fix:** Add a Block timeout and rotate or cap deadLetter.json.
- [ ] 🔴 **Failure modes are listed for each operation.** DESIGN covers retry and give-up but not publish failure causes (paused, unknown channel, type mismatch, persist failure). **Fix:** Add a failure table for each public operation.
- [ ] 🔴 **No failure is silent.** giveUp ignores deadLetter() returning false on IOException, then acks and deletes the persisted copy, losing the envelope silently. **Fix:** If the dead-letter write fails, keep the persisted copy and notify the listener.
- [ ] 🔴 **Failure paths and concurrency are tested, and time and I/O can be faked.** Tests cover consumer exceptions and refused forwards but use sleeps; there is no crash-mid-write test and no injectable clock or file system (TODO). **Fix:** Add fault-injection tests and inject the clock and store.
- [ ] 🔴 **Documentation matches the code.** TODO still lists retry backoff as missing; DESIGN says a full queue fails send(), ignoring the four policies; the routing-slip pseudocode predates the restore logic. **Fix:** Update TODO and DESIGN to match the code.
- [ ] 🔴 **The project can continue if its owner is unavailable.** CI shows the build, but there is no written release procedure or recoverable JitPack/repo access. **Fix:** Write a release runbook.
- [ ] 🔴 **Contracts are machine-readable and tested.** CORRECTNESS_SUITE.md is prose that each port re-implements; there are no shared machine-readable vectors (TODO). **Fix:** Publish shared test vectors.
- [ ] 🔴 **Change follows compatibility rules.** No compatibility or deprecation rules for consumers. **Fix:** State additive-only and deprecation rules.
- [ ] 🔴 **Delivery semantics and ordering are stated for each channel.** Delivery levels are stated but ordering for each channel is not. **Fix:** Add ordering to the delivery table.
- [ ] 🔴 **Complexity does not exceed team capacity.** Seven language ports kept in step by one maintainer with prose-only conformance. **Fix:** Automate cross-port conformance to cut the load.
- [ ] 🟡 **Persistence sits behind a boundary.** SEDAMessageChannel does file I/O directly in persist, removePersisted, deadLetter, appendDelivered and sendUnprocessed. **Fix:** Extract an internal EnvelopeStore class for persistence, dead letters and the delivered log.
- [ ] 🟡 **Components are cohesive and of reasonable size.** SEDAMessageChannel (~600 lines) combines queueing, delivery, retry, dead-letter, persistence and dedup. **Fix:** Split out the store and the retry scheduler.
